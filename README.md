# roboarm_blue

The GTAC robotic arm website and board firmware, with the iPad connecting to
the arm over **Bluetooth** instead of the board's Wi-Fi.

| Part | Where |
|---|---|
| Website (lessons, build steps, biomimicry library) | the top of this repo |
| Robot controller (Muscle sensor and Remote tabs, code canvas) | `remote/`: open it in the **Bluefy** app and tap **Connect your robot** |
| LMS-ESP32 firmware, hub program, provisioning | `lms_esp32/` (see its README) |

Made from the `roboarm` site (roboarm.gtac.edu.au) and the legodisco firmware.
The hub program is the same as the Wi-Fi version.
